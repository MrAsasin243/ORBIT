# Orbit v5 — читаемый интерфейс

Orbit — автономное приложение для управления задачами, целями, временем, обучением и подготовкой к экзаменам. Оно работает на GitHub Pages без собственного сервера; данные хранятся локально в браузере.

## Что изменено в v5

- Увеличен общий базовый размер текста и размер мелких подписей/элементов управления.
- Карточки экзаменов получили крупную типографику: вопрос около 21 px, ответ около 20 px на широком экране.
- Математическая разметка MathJax увеличена отдельно от обычного текста.
- В разделе «Настройки и данные» добавлен выбор масштаба интерфейса: 100%, 110%, 120%, 130%.
- Добавлен выбор размера формул: 115%, 125%, 140%, 155%.
- Масштаб интерфейса и размер формул сохраняются в локальных настройках браузера отдельно от пользовательских данных Orbit; настройки не попадают в JSON-экспорт.
- Обновлена версия кеша Service Worker, чтобы браузер загрузил новый интерфейс вместо старой копии.

## Установка на GitHub Pages

Загрузи в корень репозитория все файлы из архива:

- `index.html` — приложение;
- `sw.js` — офлайн-кеш;
- `manifest.webmanifest` — параметры установки PWA;
- `icon.svg`, `icon-192.png`, `icon-512.png` — иконки;
- `README-orbit-v5.md` — эта инструкция.

В GitHub открой **Settings → Pages**, выбери публикацию из ветки `main` и папку `/root`.

## Использование настроек чтения

Открой **Настройки и данные → Размер текста и формул**. По умолчанию используется масштаб интерфейса 110% и размер формул 125%. При необходимости можно увеличить интерфейс до 130%, а формулы — до 155%. Эти параметры действуют на конкретный браузер/устройство.

## Хранение данных

Рабочие данные сохраняются в `localStorage`. Для переноса данных между устройствами используй полный экспорт JSON и импорт на другом устройстве. Регулярно создавай резервные копии.

## Ограничение офлайн-режима

Сам интерфейс и уже закешированные ресурсы доступны офлайн. MathJax и вспомогательные библиотеки кешируются после первой успешной загрузки с CDN; при самом первом открытии с отключённым интернетом математические формулы могут не отрисоваться до загрузки MathJax.
