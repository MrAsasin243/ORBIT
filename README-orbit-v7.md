# Orbit v7 — офлайн-LaTeX и мобильная адаптация

## Что изменено

- MathJax 3.2.1 включён в комплект локально: `vendor/mathjax/es5/`.
- Для LaTeX больше не нужен CDN. Скрипты расширений и шрифты загружаются с того же сайта.
- Service Worker заранее кеширует всю локальную сборку MathJax (включая шрифты, расширения и ресурсы доступности).
- Обновлён кеш Service Worker: `orbit-shell-v5-offline-math`.
- Добавлена отсутствовавшая в предыдущем наборе `icon.svg`, которая уже была указана в manifest и Service Worker.
- Мобильная навигация: выдвижная боковая панель с затемнением, закрытие по нажатию вне панели и по Escape, нижняя панель быстрого доступа к основным разделам.
- Переработаны мобильные сетки, карточки, формы, диалоги, графики, списки Anki, журнал тренировок и поля подходов; учтены safe-area отступы устройств с вырезами.
- Математические формулы на небольших экранах можно прокручивать по горизонтали, не сжимая всю страницу.

## Установка на GitHub Pages

1. Распакуй архив целиком.
2. Загрузи **все содержимое** в корень GitHub-репозитория. Не пропускай папку `vendor`.
3. Включи GitHub Pages для ветки и папки, где лежит `index.html`.
4. Открой опубликованный сайт с интернетом. Дождись, пока Service Worker завершит установку и кеширование. Первый визит и первая установка требуют сети, чтобы браузер мог получить файлы сайта.
5. После этого Orbit можно запускать без интернета как установленное PWA или из кеша браузера. LaTeX рендерится локальной библиотекой.

## Установка на телефон

- Android: открой сайт в Chrome → меню браузера → «Установить приложение» / «Добавить на главный экран».
- iPhone/iPad: открой сайт в Safari → «Поделиться» → «На экран Домой».
- На узком экране внизу появится панель «Обзор / Задачи / Экзамены / Спорт / Разделы». В «Разделы» доступна полная навигация.

## Локальный запуск с компьютера

Чтобы проверить комплект офлайн через локальный сервер, открой терминал в распакованной папке и выполни:

```bash
python -m http.server 8000
```

Затем открой `http://localhost:8000`. Интернет для этого локального запуска не нужен: все файлы MathJax и шрифты уже находятся в распакованном комплекте. Service Worker поддерживается на localhost и HTTPS.

## Важно

- Не открывай `index.html` двойным щелчком, если хочешь проверить Service Worker: браузерные ограничения `file://` могут запрещать работу service worker и загрузку локальных шрифтов. Используй GitHub Pages или `localhost`.
- Формулы работают без интернета после того, как сайт был загружен и установлен/закеширован хотя бы один раз.
- Импорт некоторых форматов Anki (`.apkg`) по-прежнему может загружать дополнительные библиотеки при первом использовании. Это не влияет на уже импортированные карточки и офлайн-рендеринг LaTeX.
- Все личные данные Orbit остаются в `localStorage` браузера; резервные копии JSON по-прежнему необходимы.
