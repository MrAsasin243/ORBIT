# Orbit — обновление серверного режима для локальной сети

Это **патч к уже установленному Orbit v7**, а не полный архив приложения. Он добавляет серверное хранение на Python + SQLite и синхронизацию интерфейса с общей базой.

## Что входит в обновление

- `index.html` — обновлённый интерфейс с входом в Orbit Server, статусом синхронизации, обновлением из сервера и JSON-экспортом.
- `sw.js` — новый кеш и исключение `/api/` из Service Worker: API-запросы всегда идут в работающий сервер и не подменяются офлайн-кешем.
- `server.py` — сервер HTTP, API, парольная аутентификация, SQLite, резервные снимки и статическая раздача сайта.
- `start-server.bat` — запуск на Windows.
- `start-server.sh` — запуск на Linux/macOS.
- `data/.gitignore` — не позволяет случайно отправить базу и пароль в GitHub.

Папку `vendor/mathjax`, иконки и `manifest.webmanifest` из установленного v7 удалять или заменять не нужно.

## Установка патча

1. Сделай JSON-экспорт текущих данных Orbit на всякий случай.
2. Распакуй архив обновления **поверх существующей папки проекта**, где находится `index.html`.
3. Разреши замену `index.html` и `sw.js`.
4. Убедись, что новые `server.py`, `start-server.bat`, `start-server.sh`, `README_SERVER_UPDATE.md` и папка `data` появились рядом с `index.html`.
5. Не удаляй существующие `vendor/`, `manifest.webmanifest` и файлы иконок.

Для сервера нужен Python 3.9 или новее. Сторонние Python-пакеты устанавливать не требуется.

## Запуск на Windows

1. На компьютере, который будет постоянно хранить данные, открой папку Orbit.
2. Дважды нажми `start-server.bat`.
3. При первом запуске сервер создаст пароль и один раз покажет его в консольном окне. **Сохрани пароль.** В файл конфигурации записывается только его PBKDF2-хеш.
4. В окне появятся адреса:
   - на самом компьютере: `http://127.0.0.1:8765`;
   - в локальной сети: например `http://192.168.1.25:8765`.
5. На компьютере-сервере открой `http://127.0.0.1:8765`. На телефоне и других компьютерах, подключённых к той же сети Wi-Fi/LAN, открывай IP-адрес из консоли.
6. Введи пароль в Orbit. После входа данные загружаются из общей базы SQLite.

Если Windows Firewall спросит разрешение, разреши доступ только для **частных сетей**. Публичные сети не отмечай.

## Как перенести существующие данные

Есть два сценария.

### Если локальные данные находятся в том же браузере и на том же адресе

При первом подключении к пустой серверной базе Orbit обнаружит локальные данные и предложит перенести их на сервер.

### Если данные находятся на GitHub Pages или другом адресе

1. Открой старый локальный Orbit на прежнем адресе.
2. Перейди в «Настройки и данные» и сделай полный экспорт JSON.
3. Открой адрес Orbit Server, войди под паролем.
4. Перейди в «Настройки и данные» → «Импортировать JSON» и выбери файл.
5. После импорта данные сохранятся в общей SQLite-базе. Другие устройства увидят их после обновления.

## Общая работа с нескольких устройств

- Все устройства должны открывать **адрес компьютера-сервера**, а не GitHub Pages.
- Изменения отправляются на сервер автоматически после короткой задержки.
- Остальные подключённые устройства проверяют изменения примерно каждые 7 секунд.
- Если два устройства изменили данные одновременно, Orbit обнаружит конфликт и не станет молча перезаписывать более свежую версию. Можно сохранить локальную копию JSON и загрузить актуальную серверную версию.
- В «Настройки и данные» кнопка «Экспорт JSON» выгружает текущий набор данных в стандартном формате Orbit. Его можно импортировать в автономную версию на GitHub Pages или локальную копию.
- Кнопка «Серверная копия» создаёт дополнительный снимок данных в SQLite.

## Где находятся серверные данные

После первого запуска сервер создаёт:

- `data/orbit.sqlite3` — основная база Orbit;
- `data/server-config.json` — соль и PBKDF2-хеш пароля.

Эти файлы остаются на компьютере-сервере. Внутренняя папка `data` закрыта от загрузки через HTTP. Правило `data/.gitignore` исключает её содержимое из Git.

Перед крупными изменениями сервер автоматически создаёт снимок не чаще одного раза за 12 часов; также можно вручную создать снимок кнопкой в настройках. Хранится до 30 последних серверных снимков.

## Смена пароля и порта

Останови сервер через `Ctrl+C`. В терминале, открытом в папке Orbit, выполни:

```powershell
py -3 server.py --set-password "новый-длинный-пароль"
```

После смены пароля сервер запустится снова. Для запуска на другом порту:

```powershell
py -3 server.py --port 8766
```

## Важные ограничения безопасности

- Это сервер **для доверенной локальной сети**, не публичный интернет-сервис.
- Соединение использует HTTP без TLS. Пароль и данные не шифруются на уровне сети; используй только доверенную домашнюю/рабочую сеть.
- Не настраивай проброс порта на роутере и не публикуй этот сервер в интернете.
- Не коммить содержимое `data/` в GitHub. В патч добавлено правило `.gitignore` внутри этой папки.
- Сервер и данные доступны, пока включён компьютер-хост и запущено окно сервера.
- Одновременное редактирование поддерживается с обнаружением конфликта, но это не Google Docs: автоматического слияния двух конкурирующих изменений нет.
- При отсутствии сервера браузер продолжает работать локально через localStorage. Серверные данные остаются на хосте; экспорт JSON — способ переноса в автономную версию.

## GitHub Pages и автономный режим

GitHub Pages по-прежнему может использоваться как автономная версия Orbit с localStorage. Чтобы работать с общей серверной базой, открывай сайт с IP-адреса компьютера, где запущен `server.py`. Оба режима используют один интерфейс, а формат JSON совместим между ними.
