Подготовка к экзаменам

Иди по билетам по порядку, воспроизводи ответ без подсказок, затем проверяй себя. Ошибочные карточки вернутся в текущий проход, освоенные — по расписанию.

Пока нет наборов карточек

Импортируй колоду Anki или создай пустой набор билетов. Поддерживаются `.apkg` и текстовые экспорты Anki `.txt`, `.tsv`, `.csv`.

Метод подготовки1. Прочитай вопрос и попробуй полностью воспроизвести ответ по памяти. 2. Открой ответ и сравни с тем, что воспроизвёл. 3. Отметь честный результат. Карточки с ошибками вернутся через несколько следующих билетов, а освоенные появятся снова через заданный интервал.

УПРАВЛЕНИЕ ДАННЫМИ

Настройки и данные

Приложение работает без сервера. Экспортируй резервную копию регулярно.

Размер текста и формул

Настрой масштаб всего интерфейса и отдельно размер математических формул в экзаменационных карточках. Выбранные параметры сохраняются в этом браузере.

Изменение масштаба не затрагивает данные задач и карточек. Для формул в экзаменационном режиме достаточно изменить второй параметр.

Резервное копирование

Полный архив JSON содержит задачи, цели, проекты, время, учебные темы, колоды экзаменов с карточками, расписание повторений, привычки, тренировки с упражнениями и подходами, обзоры и игровой прогресс.

Автосохранение включено в этом браузере
Импорт заменяет текущие данные. Перед импортом автоматически создаётся точка восстановления.
Локальные точки восстановленияХранятся в этом браузере

Экспорт таблиц CSV

Выгрузи отдельные наборы данных для Excel, LibreOffice или дальнейшего анализа.

Файлы используют UTF-8 с BOM и разделитель «;» для корректного открытия в русской локали Excel.

Установка и офлайн-режим

Orbit можно установить как приложение. Библиотека MathJax и её шрифты входят в комплект сайта и сохраняются офлайн-кешем при установке PWA. Формулы работают без CDN и без интернета после первого успешного открытия приложения. Для импорта новых APKG-пакетов отдельные библиотеки импорта могут загружаться из сети.

Проверка поддержки установки…
Для полного офлайн-режима загрузи все файлы комплекта, включая папку vendor/mathjax, sw.js, manifest.webmanifest и иконки.

Как работает хранение

Информация хранится в localStorage браузера на этом устройстве и не отправляется на сервер. Очистка данных сайта или браузера может удалить записи.

LOCAL-FIRST
Файл HTML можно разместить на GitHub Pages. Для переноса данных между компьютерами используй экспорт и импорт JSON. Сам HTML-файл не содержит твою личную статистику.

Сброс данных

Удаляет задачи, цели, записи времени, тренировки и игровой прогресс из локального хранилища. Это действие нельзя отменить без JSON-резервной копии.

Правила начисления опыта

Опыт начисляется один раз при первом переводе задачи в статус «Выполнено». Повторное открытие и закрытие задачи не начисляет XP повторно.

Высокий приоритет30 XP
Средний приоритет20 XP
Низкий приоритет10 XP
Уровень повышается каждые 100 XP. Время не конвертируется в XP, чтобы игровой прогресс нельзя было накручивать длинными или случайными таймер-сессиями.

Импорт текстового экспорта Anki

HTML-разметка полей сохраняется. Для формул используй стандартные разделители LaTeX: \(…\), \[ … \] или $$…$$. В современных APKG шаблон может быть заменён представлением «первое поле → вопрос, остальные поля → ответ».
